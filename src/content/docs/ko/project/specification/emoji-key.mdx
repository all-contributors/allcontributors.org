Every kind of contribution has an emoji, and the contributors table shows one emoji for each thing a person did. This page lists all of them, together with the keyword that you use to add a contribution with the [bot](/en/app) or the [CLI](/en/cli). Each row says what the type stands for and gives a few examples, which helps when you aren't sure which type fits.

## Contributions

To record a contribution, use one or more keywords from the Contribution column. The CLI expects the keyword exactly as written, including capitalization, so use `eventOrganizing` and not `eventorganizing`. The bot ignores capitalization and also understands the words in the Bot aliases column. Because `project` is one of them, a request such as "add @jane to the project for code" also credits the person for project management.

## Types of your own

A project that needs a contribution type that isn't in this list can define its own with the `types` option, which is described in [Customize the table](/en/configuration/guides/customize-table#add-your-own-contribution-types). The specification asks projects that deviate from the standard categories to document their own definitions in their `CONTRIBUTING` file.
