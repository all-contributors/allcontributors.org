The All Contributors app is a GitHub App that keeps the contributors table of your project up to date. Without it, thanking someone who wrote documentation or answered questions means editing your `README.md` by hand, looking up their avatar and picking the right emoji. With it, you write one comment and review one pull request. Because it answers to comments, people often call it the bot.

## How it works

You mention `@all-contributors` in a comment on an issue or pull request and say who to add and for which kind of contribution, for example `@all-contributors please add @jane for docs`. The app looks up Jane's GitHub profile, adds her to the `contributors` list in your `.all-contributorsrc` file and regenerates the table in the files you configured. It then opens a pull request with those changes and replies in your comment with a link to it.

<ThemedImage name="comment-thread" alt="A GitHub pull request conversation in which a maintainer comments that @allcontributors should add @trueberryless for code, design, content, infra and doc, and the allcontributors bot replies that it has put up a pull request." />

Nothing changes on your default branch until you merge that pull request, so you always get to look at the result first.

## What you need

The app works with repositories hosted on GitHub. If your project lives on GitLab, or if you want to add contributors from a terminal or a CI job, use the [CLI](/en/cli) instead. The two tools read and write the same `.all-contributorsrc` file, and [Choose a tool](/en/project/about/tools) helps you pick between them.
