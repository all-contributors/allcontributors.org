The All Contributors Bot allows you to quickly add contributors to your project, including people who don't push code, using a simple command within an issue or pull request comment. The All Contributors Bot does three things:

1. It creates and maintains a contributor table following the [All Contributors specification](/en/project/specification/requirements) so you don't have to. It keeps the contributor table of your project up to date.
2. It allows you to add new contributors to that table using simple commands on GitHub.
3. It allows you to quickly recognize contributors who won't get recognized through typical commit workflows and code contributions for things like ideas, translations, bug reports, and more!

Without the Bot, thanking someone who wrote documentation or answered questions means updating a table in your `README.md` file by hand, looking up their GitHub profile picture (avatar), and picking the right emoji for their contribution type. Using the Bot, you add one comment to an issue or pull request tagging the contributor for a specific contribution, and the Bot opens a pull request to add them to the contributor table for you.

:::note
The All Contributors Bot only works with repositories hosted on GitHub. If your project lives on GitLab or another platform, or if you want to add contributors from a terminal or using a Continuous Integration (CI) job, use the [CLI](/en/cli) instead. The two tools read and write the same `.all-contributorsrc` file, and [Choose a tool](/en/project/about/tools) helps you pick between them.
:::

## How the All Contributors Bot works

Here's how the Bot works on GitHub. Below, we assume you are using the [default configuration](/en/app/reference/configuration), which adds the contributor table to your `README.md` file.

1. First, you mention `@all-contributors` in an issue or pull request comment. You ask it to add a specific contributor by username and specify what type of contribution they made. For example:

   `@all-contributors please add @janedoe for doc`

   Contribution types like `doc` come from the [emoji key](/en/project/specification/emoji-key).

2. Once you call the Bot, it looks at janedoe's GitHub profile, adds her to the `contributors` list in your `.all-contributorsrc` file (the configuration file for the Bot), and regenerates the contributor table in your `README.md` file (or in another file if you [changed the default configuration](/en/app/reference/configuration)).
3. Next, the Bot opens a pull request with the changes to `.all-contributorsrc` and your `README.md` file.
4. Finally, the Bot replies in the issue or pull request where you called it with a link to the open pull request.

Once that process is complete, you can merge the pull request, and the new contributor will appear in your `README.md` file.

:::tip
Because the Bot opens a pull request, you can review the changes that it makes before merging them into your default branch.
:::
