All Contributors is a way to thank everyone who helps your open source project. People contribute in many ways: they write code, but they also fix documentation, design interfaces, answer questions, translate pages, organize events and report bugs. A list of the people who committed code leaves most of that work out, and All Contributors exists to fix that.

The idea behind it is short:

> Use the project `README.md` (or another prominent public documentation page in the project) to recognize the contributions of members of the project community.

Because anyone who contributes in any way belongs in that list, the project defines a table that shows each person with their avatar, a link and one emoji for every kind of contribution.

![An example of a contributors table on GitHub, showing avatars, names and emojis.](@/assets/reference/contributors-table-small.png)

## The parts of the project

All Contributors has a few parts that work together, and you can use as many of them as you like.

The [specification](/en/project/specification/requirements) says what the table has to contain, and the [emoji key](/en/project/specification/emoji-key) lists the kinds of contributions and their emojis. You can follow the specification by editing your README by hand.

The [app](/en/app) and the [CLI](/en/cli) are tools that maintain the table for you. The app does it from a comment on GitHub, and the CLI does it from the command line, so neither requires you to look up avatars or emojis.

The project is run by volunteers, and you are welcome to help. [Contributing](/en/project/contributing/guidelines) explains how to improve the documentation, translate it or work on the tools.
