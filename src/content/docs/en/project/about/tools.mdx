You can follow the All Contributors specification by editing your README by hand. For each new contributor that means finding their profile, copying their avatar address and picking the right emoji, and the work grows with every person. The app and the CLI do that part for you, and which one to use depends on where your project is hosted and how you like to work.

## The app

The [app](/en/app) is a GitHub App. You install it on your repositories and mention `@all-contributors` in an issue or pull request comment, for example `@all-contributors please add @jane for docs`. The app opens a pull request with the change, and you merge it when you are happy with it. Nothing has to be installed in your project, and the people who help you can ask for recognition themselves without needing write access.

## The CLI

The [CLI](/en/cli) is an npm package that you run in a terminal, in a script or in a CI job. It changes the files in your working directory, and it can commit the result. It works with repositories on GitHub and on GitLab, including servers you host yourself, and it can compare your commits with your table to find people you forgot.

## The two side by side

| | App | CLI |
| --- | --- | --- |
| Hosting | GitHub | GitHub and GitLab, including self-hosted servers |
| You use it by | Commenting on an issue or pull request | Running a command |
| What you install | The GitHub App, on the repositories you choose | The `all-contributors-cli` package, which needs Node.js |
| What you get | A pull request with the change | Changed files, and a commit if you turn that on |
| Finds missing contributors | No | Yes, with `check` |

The two tools write the same `.all-contributorsrc` file and the same table, so you can switch from one to the other, or use both in the same repository, without converting anything. [How All Contributors works](/en/project/about/how-it-works) explains the file and the table.
