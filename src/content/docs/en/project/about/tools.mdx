You can follow the All Contributors specification by editing your README by hand, but every new contributor means looking up a profile, copying an avatar address and picking the right emoji. The [bot](/en/app) and the [CLI](/en/cli) do that work for you. Which one fits depends on where your project is hosted and how you like to work:

| | Bot | CLI |
| --- | --- | --- |
| Hosting | GitHub | GitHub and GitLab, including self-hosted servers |
| You use it by | Commenting on an issue or pull request | Running a command in a terminal, a script or a CI job |
| What you install | The GitHub App, on the repositories you choose | The `all-contributors-cli` package, which needs Node.js |
| What you get | A pull request with the change | Changed files, and a commit if you turn that on |
| Who can ask | Anyone who can comment, without write access | People who can push to the repository |
| Finds missing contributors | No | Yes, with `check` |

Both tools read and write the same [configuration](/en/configuration) and the same table, so you can switch from one to the other, or use both in the same repository, without converting anything.
