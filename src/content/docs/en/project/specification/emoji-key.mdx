Every kind of contribution has an emoji, and the contributors table shows one emoji for each thing a person did. This page lists all of them, together with the keyword that you use to add a contribution with the [app](/en/app) or the [CLI](/en/cli). Each row says what the type stands for and gives a few examples, which helps when you aren't sure which type fits.

## Contributions

To record a contribution with a tool, use one or more of the keywords from the Contribution column. The CLI expects the keyword exactly as written, including capitalization, so use `eventOrganizing` and not `eventorganizing`. The app is more forgiving and also understands plurals and a few synonyms, which the [comment syntax](/en/app/guides/usage) reference lists.

## Types of your own

A project that needs a contribution type that isn't in this list can define its own with the `types` option, which is described in [Customize the table](/en/app/reference/configuration). The specification asks projects that deviate from the standard categories to document their own definitions in their `CONTRIBUTING` file.
