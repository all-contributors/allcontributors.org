The CLI is distributed on [npm](https://www.npmjs.com/) as `all-contributors-cli`, and the command it installs is called `all-contributors`. It needs Node.js 22.22.0 or later. Because you use it as part of your project's workflow, you normally install it as a development dependency of that project.

## Install it in your project

Run the install command of your package manager in the root of the project:

<Tabs syncKey="pkg">
<TabItem label="npm">

```sh
npm install --save-dev all-contributors-cli
```

</TabItem>
<TabItem label="pnpm">

```sh
pnpm add --save-dev all-contributors-cli
```

</TabItem>
<TabItem label="Yarn">

```sh
yarn add --dev all-contributors-cli
```

</TabItem>
</Tabs>

Arch Linux users can install the [`all-contributors-cli`](https://aur.archlinux.org/packages/all-contributors-cli) package from the AUR instead.

## Run the command

Once the package is installed, run the `all-contributors` command through your package manager so that it finds the local copy:

<Tabs syncKey="pkg">
<TabItem label="npm">

```sh
npx all-contributors --help
```

</TabItem>
<TabItem label="pnpm">

```sh
pnpm all-contributors --help
```

</TabItem>
<TabItem label="Yarn">

```sh
yarn all-contributors --help
```

</TabItem>
</Tabs>

You can also call the executable directly with `./node_modules/.bin/all-contributors`. The rest of this documentation writes `all-contributors` for the command, and you add the prefix that matches your setup.

## Run it without installing it

To try the CLI or to run it once, use the full package name. The name matters, because the `all-contributors` package on npm is a different package that isn't this CLI:

<Tabs syncKey="pkg">
<TabItem label="npm">

```sh
npx all-contributors-cli init
```

</TabItem>
<TabItem label="pnpm">

```sh
pnpm dlx all-contributors-cli init
```

</TabItem>
<TabItem label="Yarn">

```sh
yarn dlx all-contributors-cli init
```

</TabItem>
</Tabs>

## Add shortcuts to your scripts

If you add contributors often, shortcuts in the `scripts` field of your `package.json` save typing:

```json
{
  "scripts": {
    "contributors:add": "all-contributors add",
    "contributors:generate": "all-contributors generate"
  }
}
```

With those entries you run `npm run contributors:add -- jane doc` or `pnpm contributors:add jane doc`. With npm the `--` is needed so that the arguments reach the command and not npm itself.
