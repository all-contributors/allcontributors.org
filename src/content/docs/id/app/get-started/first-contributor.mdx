This walkthrough adds your first contributor with the All Contributors Bot. It assumes that you have [installed the bot](/en/app/get-started/installation) on your repository.

<Steps>

1. Open an issue or a pull request

   The bot responds to comments in any issue or pull request of the repository. The natural place is the conversation where the person helped, such as the pull request that fixed a bug. To try the bot out, create a new issue.

2. Mention the bot

   Comment with the bot's name, the person's username and their [contribution type](/en/project/specification/emoji-key). Replace `janedoe` with a real GitHub username:

   ```plaintext wrap
   @all-contributors please add @janedoe for doc
   ```

3. Wait for the reply

   After a short moment, the bot replies in the same conversation with a link to a new pull request, for example "I've put up a pull request to add @janedoe! 🎉". If it replies with something else, see [Troubleshooting](/en/app/guides/troubleshooting).

   For more about the different replies the bot might send, see [Usage](/en/app/guides/usage#how-the-bot-replies).

4. Review the pull request

   With the default settings, the pull request is titled `docs: add janedoe as a contributor for doc`, and it links back to your comment. It adds janedoe to the `contributors` list in `.all-contributorsrc` and updates the table in your README, or in the files you [configured](/en/configuration).

   :::tip
   If the bot created your configuration, the pull request description ends with `[skip ci]`, which tells many continuous integration services to skip checks. See configuration [options](/en/configuration/reference/options) to learn more.
   :::

5. Merge it

   Once you merge the pull request, janedoe appears in the contributor table.

</Steps>

[Add contributors](/en/app/guides/usage) explains how to credit several contribution types or several people at once.
