# Spec: Fix Broken Bot Usage Anchor and Enable Link Validation in CI (#898)

## 1. Overview & Context

In `allcontributors.org`, internal link validation using `starlight-links-validator` is configured conditionally via `configs/plugins.config.ts`:

```typescript
export const Plugins = [
  starlightThemeFlexoki(),
  ...(process.env.CHECK_LINKS
    ? [
        starlightLinksValidator({
          errorOnFallbackPages: false,
          errorOnInconsistentLocale: true,
        }),
      ]
    : []),
  starlightImageZoom(),
  starlightHeadingBadges(),
];
```

However, prior to this change:

1. `CHECK_LINKS` was not set in GitHub Actions CI workflows (`.github/workflows/build-website.yaml`), so link validation did not run on PRs or pushes.
2. `package.json` lacked a dedicated script to run `astro build` with `CHECK_LINKS=true`.
3. In `src/content/docs/en/bot/configuration.mdx`, line 37 referenced `[@all-contributors add](/en/bot/usage#all-contributors-add)`, which points to a nonexistent heading anchor in `src/content/docs/en/bot/usage.mdx`. The correct anchor generated by the heading `## Adding contributions` is `#adding-contributions`.

When running `CHECK_LINKS=true pnpm build`, the build failed with:

```text
[ERROR] [starlight-links-validator] Links validation failed.
| /en/bot/usage#all-contributors-add
╰── invalid hash
```

## 2. Goals & Objectives

- Correct the anchor reference in `src/content/docs/en/bot/configuration.mdx` from `#all-contributors-add` to `#adding-contributions`.
- Expose a convenient npm script `"build:check-links": "CHECK_LINKS=true astro build"` in `package.json`.
- Enforce internal link validation in CI by adding `CHECK_LINKS: "true"` to the `Build website` step in `.github/workflows/build-website.yaml`.
- Ensure all CI build checks and markdown linting pass with zero warnings and zero errors.

## 3. Scope & Contracts

### 3.1 Documentation Anchor Fix

- Target: `src/content/docs/en/bot/configuration.mdx`
- Change:

  ```markdown
  - | `contributors`                   | List of contributors for this project, this is updated by [@all-contributors add](/en/bot/usage#all-contributors-add)                                                                                                                        |                                                                                                             |
  + | `contributors`                   | List of contributors for this project, this is updated by [@all-contributors add](/en/bot/usage#adding-contributions)                                                                                                                        |                                                                                                             |
  ```

### 3.2 Package Scripts

- Target: `package.json`
- Add `"build:check-links": "CHECK_LINKS=true astro build"` under `"scripts"`.

### 3.3 CI Workflow

- Target: `.github/workflows/build-website.yaml`
- In job `build`, step `Build website`, inject environment variable `CHECK_LINKS: "true"`.

## 4. Verification Plan

1. **Link Validation Build**: Run `CHECK_LINKS=true pnpm build` (or `pnpm build:check-links`) and confirm `starlight-links-validator` passes with 0 invalid links.
2. **Standard Build**: Run `pnpm build` to confirm default builds succeed without error.
3. **Markdown Lint**: Run `pnpm lint` and confirm markdownlint succeeds without violations.
